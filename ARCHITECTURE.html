🏗️ Architecture - Système de Demande de Congé Public

📊 Flux d'utilisation

1. Connexion (ID simple)
L'employé accède à /public/conge/login et entre son ID
2. Validation & Stockage en session
L'ID est validé et stocké dans la session HTTP
3. Formulaire de demande
L'employé remplit la demande (dates, motif)
4. Création de la demande
La demande est créée avec l'ID de la session
5. Consultation & Gestion
L'employé peut voir ses demandes précédentes
6. Déconnexion
L'ID est supprimé de la session

🔗 Points d'accès (Endpoints)

GET /public/conge/login - Affiche le formulaire de connexion
POST /public/conge/login - Traite la connexion (stocke l'ID en session)
GET /public/conge/nouvelle-demande - Affiche le formulaire de demande
POST /public/conge/creer - Crée une nouvelle demande
GET /public/conge/mes-demandes - Liste les demandes de l'employé
GET /public/conge/logout - Déconnecte l'employé

🔒 Sécurité

⚠️ Mode Simulation : Ce système est une simulation pour permettre les tests sans authentification Spring Security.

Actuellement : N'importe qui peut entrer n'importe quel ID d'employé existant

💾 Gestion de la session

Attributs stockés dans la session :

// Après connexion réussie : session.setAttribute("employeId", personnel.getId_personnel()); session.setAttribute("employeNom", personnel.getCandidat().getNom()); // Récupération dans les pages : Integer employeId = (Integer) session.getAttribute("employeId"); // Suppression à la déconnexion : session.removeAttribute("employeId"); session.removeAttribute("employeNom");

✨ Fonctionnalités implémentées

  • Connexion simple avec ID d'employé
  • Validation de l'existence et de l'activation de l'employé
  • Stockage sécurisé en session HTTP
  • Affichage brut de l'ID connecté dans la demande
  • Vérification du solde de congé
  • Création de demande avec les règles métier
  • Consultation de l'historique des demandes
  • Gestion des statuts (En attente, Approuvée, Rejetée)
  • Déconnexion propre
  • Interface responsive et user-friendly

🚀 Étapes de test

  1. Accéder à http://localhost:8080/public/conge/login
  2. Entrer un ID d'employé existant (ex: 1)
  3. Vérifier que l'ID s'affiche dans le formulaire
  4. Remplir les dates et créer une demande
  5. Vérifier la demande dans "Mes demandes"
  6. Tester la déconnexion
