I. Processus de recrutement
	Acteurs : 
		- Utilisateur (candidat)
		- RH (recruteur)
		- Admin

	Liste de fonctionnalités par acteur : 
		- Utilisateur (Candidat) : 
			- Compte & Profil :
				- S'inscrire
				- Se connecter
				- Modifier ses informations personnelles
			
			- Consultation & Postulation : 
				- Voir la liste des postes disponibles
				- Filtrer / rechercher une offre
				- Voir les détails d’une offre
				- Postuler à un poste
				- Voir la liste de ses candidatures
				- Voir les statuts et avancements (ex : en attente, test, entretien, accepté, refusé)
			
			- Tests & Entretiens : 
				- Faire un test QCM
				- Voir le résultat d’un test
				- Voir le résultat de l'entretien (accepté/refusé/pool talent)
			
			- Décision finale : 
				- Voir le résultat final d’une postulation
				- Recevoir un contrat d’essai (texte)
				- Accepter ou refuser le contrat d’essai (PDF, si accepté)

		- RH (Recruteur) : 
			- Gestion des offres : 
				- CRUD d'annonce de poste
			
			- Gestion des tests : 
				- CRUD de test
			
			- Gestion des candidatures : 
				- Voir la liste des candidatures par poste
				- Filtrer par statut (ex : en attente, en test, en entretien, refusée, acceptée)
				- Sélectionner une candidature pour un entretien
				- Attribuer une note d’entretien
				- Sélectionner un candidat final pour le poste
				- Envoyer un contrat d’essai au candidat
			
			- Statistiques : 
				- Voir le nombre de candidatures par poste
				- Voir les taux de réussite (test, entretien)
				- Voir un résumé des statuts (ex : 10 en attente, 5 tests, 2 entretiens…)

		- Admin : 
			- Contrôle du processus : 
				- Valider la candidature finale sélectionnée par le RH
			- Supervision: 
				- Voir toutes les annonces
				- Voir toutes les candidatures (vue globale)

	URI :
		- Utilisateur (candidat) — API /users
			- POST /users/auth/register
			- POST /users/auth/login
			- PATCH /users/candidats/me
			- GET /users/candidats/me

			- GET /users/offres
			- GET /users/offres?titre=&localisation=&type=
			- GET /users/offres/{id_poste_offre}
			- POST /users/offres/{id_poste_offre}/postulations
			- GET /users/candidats/me/postulations
			- GET /users/candidats/me/postulations/{id_postulation}
			- GET /users/candidats/me/postulations/{id_postulation}/statut

			- GET /users/tests/{id_test}/questions
			- POST /users/tests/{id_test}/submissions
			- GET /users/candidats/me/tests/{id_test}/resultat
			- GET /users/candidats/me/entretiens/{id_entretien}

			- GET /users/candidats/me/postulations/{id_postulation}/entretiens
			- GET /users/candidats/me/entretiens/{id_entretien}
			- GET /users/candidats/me/postulations/{id_postulation}/statut
			- GET /users/candidats/me/contrats/{id_contrat}
			- POST /users/candidats/me/contrats/{id_contrat}/decision

		- RH (recruteur) — API /rh
			- GET /rh/offres
			- POST /rh/offres
			- PATCH /rh/offres/{id_offre}
			- DELETE /rh/offres/{id_offre}

			- POST /rh/tests
			- PATCH /rh/tests/{id_test}
			- DELETE /rh/tests/{id_test}
			- POST /rh/tests/{id_test}/questions
			- POST /rh/questions/{id_question}/reponses

			- GET /rh/postulations
			- GET /rh/postulations/{id_postulation}
			- GET /rh/postulations?statut=?offre_id=
			- POST /rh/postulations/{id_postulation}/notes
			- POST /rh/postulations/{id_postulation}/recrutement
			- POST /rh/recrutements/{id_recrutement}/contrats
			- GET /rh/postulations/{id_postulation}/decision

			- GET /rh/stats/offres
			- GET /rh/stats/candidats
			- GET /rh/stats/tests
			- GET /rh/stats/entretiens

		- Admin — API /admin
			- PATCH /admin/recrutements/{id_recrutement}/validation
			- GET /admin/offres
			- GET /admin/postulations

II. Gestion RH
	Acteurs : 
		- Employé
		- Manager
		- RH
		- Admin

	Liste de fonctionnalités par acteur : 
		- Employé : 
			- Se connecter / Se déconnecter

			- Dossier personnel :
				- Voir sa fiche employé (identité, poste, service, contrat)
				- Mettre à jour certaines infos personnelles (adresse, contact)
			
			- Congés & absences : 
				- Voir son solde de congés (tous types : payé, maladie, exceptionnel)
				- Faire une demande de congé
				- Faire une demande d’absence (maladie, permission…)
				- Voir l’état de ses demandes (en attente / validé / refusé)
				- Voir l’historique de ses congés et absences
			
			- Temps & présence :
				- Pointer entrée / sortie
				- Pointer pause
				- Voir son récapitulatif de présence (mensuel ou journalier)
				- Voir ses retards et heures supplémentaires
			
			- Paie : 
				- Voir ses fiches de paie mensuelles
				- Télécharger une fiche de paie en PDF
				- Voir ses primes / heures sup / retenues
			
			- Communication : 
				- Messagerie RH (envoyer message + lire réponses)
				- Chatbot RH pour questions courantes (congés, paie, documents)
		
		- Manager : 
			- Supervision d’équipe :
				-  Voir la liste des employés de son service
				- Voir présence / absences / retards de l’équipe
				- Voir le calendrier des congés de son équipe
				- Voir les performances individuelles et collectives
				- Voir l’historique des postes ou mobilités au sein de l’équipe

			- Validation : 
				- Valider ou refuser les demandes de congés
				- Valider les demandes d’absence
				- Valider les feuilles de temps (présence)

			- Tableau de bord Manager : 
				- Statistiques d’équipe :
					- taux d’absentéisme
					- performance moyenne
					- ancienneté
					- distribution des postes
					- congés prévus

				- Alertes :
					- employés en retard fréquent
					- absence répétée
					- fin de contrat proche

		- RH : 
			- Gestion du personnel : 
				- Voir tous les employés
				- Créer / modifier / clôturer un contrat
				- Ajouter documents RH (CIN, diplômes, attestations)
				- Voir historique des postes et promotions
				- Suivre période d’essai, renouvellement, fin de contrat

			- Absences & congés : 
				- Voir toutes les demandes de congés / absences
				- Filtrer par service, statut, date
				- Valider / refuser les demandes
				- Voir le calendrier global des absences/congés
				- Voir les anomalies :
					- congés non validés
					- absences répétées

			- Temps & présences : 
				- Voir tous les pointages journaliers
				- Voir les retards et présences anormales
				- Voir le total des heures supplémentaires
				- Générer un relevé de présence mensuel
			
			- Paie : 
				- Générer les fiches de paie
				- Paramétrer les composants de paie (primes, heures sup, absences)
				- Export comptable / PDF
				- Vérifier régularisation : IRSA, CNAPS, OSTIE
			
			- Performance & évaluation : 
				- Faire la fiche d’évaluation d’un employé
				- Voir performances par service
				- Voir historique de performance
			
			- Tableaux de bord & statistiques : 
				- Nombre d’employés par service, genre, âge, poste
				- Taux turnover
				- Taux absentéisme
				- Ancienneté moyenne
				- Suivi fin de contrat (alertes 30 jours)
				- Suivi performance globale et par équipe
			
			- Fonctionnalités intelligentes : 
				- Prédiction du turnover
				- Détection d’anomalie sur heures / paie
				- Recommandation matching Postes ↔ Candidats (intégration module recrutement)
			
			- Communication : 
				- Messagerie avec employés

		- Admin : 
			- Paramétrages : 
				- Taux CNAPS / OSTIE / IRSA
				- Grille salariale
				- Paramètres de primes / pénalités
				- Paramétrage des rôles et permissions

			- Supervision globale : 
				- Statistiques globales RH
				- Vue consolidée de tous les employés
				- Vue consolidée des demandes / validations
				- Vue consolidée de la paie mensuelle
			
			- Audit & conformité : 
				- Voir toutes les traces et journaux (audit logs)
				- Voir historique des validations

		- Employés - API /employees
